# Interface fonts

- Display: Newsreader, static instance at weight 600 and optical size 36. Downloaded from the [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/newsreader) on 11 September 2026; SIL Open Font License included in Newsreader-OFL.txt. The static instance is generated with fontTools for reliable Unity import.
- Body: Atkinson Hyperlegible Regular and Bold, from the [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegible) on 11 September 2026; SIL Open Font License included in Atkinson-OFL.txt.

These are embedded fonts, not network-loaded resources.
